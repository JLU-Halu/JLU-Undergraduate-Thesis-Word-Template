# 吉林大学本科毕业论文（设计）Word 模板（非官方）

本仓库提供一份吉林大学本科毕业论文（设计）Word 模板。

本模板参照《吉林大学本科毕业论文（设计）工作手册》中的论文格式要求制作，主要用于帮助习惯使用 Microsoft Word / WPS 的同学进行毕业论文排版。

> 注意：本模板为个人整理的非官方模板，并非吉林大学官方发布文件。不同学院、不同年份的具体要求可能存在差异，实际提交格式请以学校、学院及指导教师发布的最新要求为准。

## 文件说明

- `吉林大学本科毕业论文（设计）Word模板.docx`：可直接编辑的 Word 模板
- `吉林大学本科毕业论文（设计）Word模板预览.pdf`：模板排版效果预览

## 使用方法

1. 下载本仓库中的 `.docx` 文件；
2. 使用 Microsoft Word 或 WPS 打开；
3. 按照模板中的标题、摘要、目录、正文、参考文献等样式替换内容；
4. 提交前请再次对照学校、学院或指导教师发布的最新格式要求检查。

本模板仅供学习、交流和排版参考使用，不保证完全符合所有学院、所有年份的毕业论文格式要求。使用者应自行核对最新官方要求。
